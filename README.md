# 한글 모아모아 수읽기

메이플스토리 한글날 미니게임 「한글 모아모아」(2026.10.01 ~ 10.14)의 현재 판과 손패 3개를 입력하면, 어느 조각을 어느 칸에 둘지 추천하는 기보판입니다.

- `index.html` 하나로 동작합니다. 브라우저에서 열면 되고, 서버나 설치가 필요 없습니다.
- 학습된 판 평가 표(약 3MB)가 페이지에 들어 있습니다.

## 사용법

1. **칸 칠하기**로 게임판을 옮겨 적습니다. 능력 아이콘이 있으면 **점찍기 아이콘 / 바꿔뽑기 아이콘**으로 위치를 찍습니다.
2. 슬롯을 고른 뒤 조각 목록에서 블록 3개를 지정하고, 점수·제거한 줄·다음 능력까지 남은 배치 수·보유 능력을 입력합니다.
3. 자동으로 계산된 **AI 추천 순위**를 누르면 판에 수순 번호가 표시됩니다.
   - 점선 줄: 수순 중 지워지는 줄
   - 사선 칸: 지운 뒤 다시 채우는 칸
4. **이 수순대로 두기**로 점수·줄 수·능력 카운트를 반영합니다. 7번째 배치 뒤 아이콘이 생기면 실제 게임 화면을 보고 위치를 찍습니다.

## 반영한 규칙 (공식 공지 기준)

- 판: 가로 10 × 세로 16. 조각 19종, 회전·반전 가능, 3개씩 지급.
- 가로줄만 제거됩니다. 지워진 줄 위쪽 줄은 내려오지 않는 것으로 처리했습니다(설정에서 변경 가능).
- 점수: 배치 칸수 + 동시 제거 줄 수에 따라 1줄 300 · 2줄 1,200 · 3줄 2,700 · 4줄 4,800 · 5줄 7,500 + 능력 획득 50점. 한 판 최대 500,000점.
- 능력: 7회 배치마다 아이콘 생성(점찍기 40% / 바꿔뽑기 60%), 보유 최대 7개, 판 위 아이콘 최대 3개.
- **조각 등장 확률은 공식 수치가 없어 가정입니다.** 1단계는 균등, 단계가 오를수록 작은 조각이 덜 나오도록 했습니다(설정에서 비율 조정).

## 추천 방식

1. **후보 수순 탐색**: 3개 조각(+점찍기)의 놓는 순서와 위치를 빔 탐색으로 찾고, 첫 수가 서로 다른 후보 8개를 고릅니다.
2. **판 평가**: 아래 두 가지를 합친 가치 함수로 판을 평가합니다.
   - 판 모양 패턴표(n-tuple): 행 쌍, 3×4·4×3·4×4·2×5·5×2 창
   - 손으로 만든 평가식 18항목: 구멍, 줄 완성도, 조각별 배치 가능 위치 수 등
3. **몬테카를로 검증**: 각 후보 수순 뒤에 무작위 미래 조각으로 설정한 깊이만큼 실제로 두어 보고, 평균 점수와 생존율로 순위를 매깁니다.

## 폴더 구성

```
index.html          빌드된 페이지 (이 파일만 열면 됨)
src/
  core.js           게임 규칙 엔진 + 빔 탐색 플래너 + 시뮬레이터
  ntv2.js           패턴표 가치 함수 (평가, 학습 갱신, 페이지용 디코더)
  app.html          페이지 템플릿 (UI, 웹 워커 몬테카를로)
  build3.js         템플릿 + 엔진 + 학습 데이터 → index.html
  weights3.json     평가식 가중치
  td2.bin           학습된 패턴표
  train3.js         평가식 가중치 학습 (CEM)
  td2.js            패턴표 TD 학습 (붕괴 감지 시 최고 저장본으로 자동 복구)
  benchV2.js        패턴표 모델 벤치마크
  bench3.js         평가식만 쓰는 모델 벤치마크
  rules_test.js     점수·줄 제거·능력 규칙 테스트
```

## 명령어 (Node.js 18+ , `src/`에서 실행)

```bash
node rules_test.js                               # 규칙 테스트
node benchV2.js 90 8 9800000 td2.bin             # 90판, 탐색 폭 8 벤치마크
node td2.js 60 0.01 td2.bin                      # 패턴표 이어서 60분 학습 (td2.bin 갱신, td2_best.bin 저장)
node build3.js td2.bin "벤치 문구"               # ../index.html 다시 빌드
```

## 한계

- 조각 확률은 추정값이라, 실제 확률과 다르면 단계가 오른 뒤의 추천 정확도가 떨어질 수 있습니다.
- 능력 아이콘이 생기는 위치는 무작위라, 시뮬레이션은 균등 무작위로 가정합니다.
- 조각 목록의 기본 방향이 게임의 기본 방향과 다를 수 있습니다. 놓을 모양은 판 위 수순 표시를 기준으로 맞추면 됩니다.
